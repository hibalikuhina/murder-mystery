# 剧本杀主持入口

本仓库用于存放可由 AI 主持的剧本。使用时，先从下方索引选择剧本，再把链接指向的主持文件交给 AI 阅读。该文件是对应剧本的主持依据；同一文件夹中的其他材料仅作补充。

## 后续收录约定

- 一个剧本对应一个独立文件夹，文件夹使用清晰的英文名称，例如 `changan-no-lanterns/`。
- 每个剧本指定**一个**供 AI 主持直接阅读的主文件，建议命名为 `host.md`。人物卡、图片等补充材料可以放在同一文件夹内。
- 在上方索引中为每个剧本添加一行，链接**直接指向主文件**，例如 `[主持文件](example-scenario/host.md)`，不要只链接到文件夹。
- 主文件应说明所需的主持规则，以及何时、如何使用同文件夹内的补充材料。若文件名不同，以索引中的链接为准。

现有《长安无灯》文件暂不迁移，也不按上述约定改写；等它在其他项目中的整理完成后，再确定最终目录和主持文件。
